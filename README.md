# codefoster.com

My website [codefoster.com](https://codefoster.com) is a statically generated blog built with [Astro](https://astro.build). Posts live as markdown in `src/content/posts/`, images in `public/files/`, and the whole thing deploys to Azure Static Web Apps via GitHub Actions on every push to `master`.

## Working on the site

```bash
npm install
npm run dev       # local dev server at localhost:4321
npm run build     # static build to dist/
npm run preview   # serve the built site
```

## Writing a post

Create `src/content/posts/<slug>.md`. The filename becomes the URL (`/<slug>/`). Frontmatter:

```yaml
---
title: My Post Title
date: 2026-06-11
categories: [Code]
tags: [astro, blogging]
---
```

Optional fields: `permalink` (override the slug) and `alias` (extra URLs that redirect to this post).

## Notes

- Legacy URL redirects: per-post `alias` frontmatter renders meta-refresh pages; fixed redirects (feeds, old `.aspx` paths) are 301s in `public/staticwebapp.config.json`.
- `trailingSlash` in the SWA config must stay `auto` — `always` adds redirects to file URLs like `/atom.xml`.
- The site was generated by Hexo from 2016–2026; it migrated to Astro in June 2026 (PR #65).
